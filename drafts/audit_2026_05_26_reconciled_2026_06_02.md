## Still actionable (the only things left)

### [ ] M4 — `prune_plaid_webhook_events` has no schedule (PARTIAL) — *the one real gap*
`migration 064` defines `prune_plaid_webhook_events(p_retention_days DEFAULT 90)`
(SECURITY DEFINER, service-role-only) but nothing invokes it. No pg_cron job, no
scheduled Edge Function call. `plaid_webhook_events` grows unbounded until something
calls it. **Fix:** add a pg_cron schedule, or invoke it once per run from
`plaid-transactions-sync`.

### [ ] M1 — Dead deps `local_auth` + `flutter_secure_storage` (OPEN)
`mobile/pubspec.yaml:24-25` still declares both; zero imports in `lib/`. Ships native
weight per ABI. **Fix:** remove, or wire `flutter_secure_storage` in (it's the obvious
home for any client-side secret material).

### [ ] C9 — Lint tightening incomplete (PARTIAL)
`mobile/analysis_options.yaml` locked `avoid_print` + `unawaited_futures`. Still
deferred (per the file's own comment): `use_build_context_synchronously: error`,
`avoid_dynamic_calls: error`, `require_trailing_commas`. Each surfaces real diffs;
do as focused PRs.

### [ ] C10 — Coverage step missing (PARTIAL)
`.github/dependabot.yml` shipped (pub + actions, weekly). But `ci.yaml` still has no
`flutter test --coverage` / Codecov step. **Fix:** add the coverage step.

### [ ] C7 — minSdk not literally pinned (PARTIAL)
`build.gradle.kts:59` pins `targetSdk = 35`, `:29` pins `compileSdk = 36`, but `:58`
is still `minSdk = flutter.minSdkVersion`. A Flutter SDK bump can shift the floor
silently. **Fix:** `minSdk = 23` literal (comment already says 23 is the intended floor).

### [ ] H1 — No FK-aware replay ordering (OPEN ✎ — deferred by design)
Drain is `created_at ASC` FIFO, no `depends_on`. Harmless today; becomes real once
Phase 3c wires child tables through the queue (parent-fails → orphaned children
retry forever). Tie this to the Phase 3c work, not before.

### [ ] X2 — `recalculateBalance` network-only (OPEN ✎ — deferred by design)
`accounts_repository.dart` — server-side compute that can't be meaningfully queued.
Flagged Phase 4 hard case in inline comments. Leave deferred.
